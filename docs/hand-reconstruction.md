# Hand-reconstructing a function

Most of the game was machine-translated (`src/auto/`, generated by `tools/gen_c.py`
from Ghidra's output) and is now edited directly: the generator no longer runs.
Functions it could not translate were written by hand in `src/game/*.c` (and the
C runtime's in `src/crt/`); `src/auto` keeps a one-line pointer where each was
(`/* 005e22ed: written by hand in src/game/fixups.c */`).  A function can be
moved between the two freely now.

## Rules

* **Exact behaviour.**  The rebuilt game is compared against the original
  screen by screen and `rand()` call by `rand()` call.  Follow the original
  machine code (`tools/show.py ADDR -d`), not Ghidra, wherever they disagree:
  the decompiler output is wrong precisely where the artifacts are.
* **Same name, same ABI.**  Define the function under its symbol name
  (`FUN_xxxxxxxx`) with the calling convention and parameter list declared in
  `src/auto/protos.h` (types must match exactly or the compiler reports
  "conflicting types").  It must pop the same number of argument bytes;
  `tools/check_game_file.py` verifies this.
* **Calls** go to other functions by name (`FUN_x`, `thunk_FUN_x` — both are
  declared in `protos.h` and resolve to the original addresses, whichever
  implementation is active there).  Win32 APIs are called normally.
* **Globals** are addressed by their original location: use
  `GLOBAL(type, 0xADDR)` (from `tools/ghidra.h`), ideally wrapped in a named
  `#define` (see `src/game/timer_display.c`).  The `DAT_xxxxxxxx` macros in
  `src/auto/globals.h` are also visible.
* **Stack layout.**  The game has harmless out-of-bounds writes between
  neighbouring locals.  If a function has local arrays or structs whose
  address escapes, keep the original frame layout: copy the `frame_` array
  and `#define local_N (*(T *)(frame_ + K))` macros from the generated
  version (offsets are relative to the original frame).
* **Register arguments.**  A few functions take an argument in a register
  (`in_EAX`, `in_ECX`, `in_AL`).  Implement the body as a C function with an
  explicit parameter and make `FUN_x` a small `__attribute__((naked))` stub
  that moves the register into that parameter, calls the body and returns with
  the original `ret N`.  Check (grep `src/auto`) whether reconstructed callers
  pass the register; report those that do not.
* **Unwind funclets / EBP-relative code** (`unaff_EBP`): MSVC emits small
  `call $L` blocks that run with the *caller's* EBP to destroy locals; the
  generator inlines the ones it understands.  Translate `EBP - N` to the
  caller's local at that frame offset (Ghidra names it `local_<N+4 hex>`).
* **Exception frames** (`fs:[0]` bookkeeping, `unaff_FS_OFFSET`) are dropped:
  the game never throws.

## Tools (run inside the container via `tools/dk`)

* `python3 tools/show.py ADDR` — generated C (with the reason it is manual)
* `python3 tools/show.py ADDR -g` — Ghidra's raw output
* `python3 tools/show.py ADDR -d` — original disassembly (needs `tools/dk`)
* `python3 tools/check_game_file.py src/game/FILE.c` — compile + ABI check
