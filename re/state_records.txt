# The game's state grouped into records (tools/state_records.py).
#
#   record TYPE instance  comment
#       old_name      member        (a loose global of src/data/gamedata.h)
#       BLOCK.member  member        (a member of a contiguity block)
#   end
#
# Each record is a run of variables lying together in the original's data
# and describing one thing; its instance is where they were (the layout and
# per-member static_asserts check it).
